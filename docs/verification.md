## E2Eランナーの制約

`npm run test:e2e`用のPlaywrightシナリオ13本を納品しています。今回、独立したGoogle Chromeの起動が実行環境内でSIGABRTになり、全13件がテスト開始前に停止しました。これはアプリの検証合格とは数えていません。代わりに上記の操作をCodex内ブラウザで実施しました。

通常のターミナルでGoogle Chromeが起動できる環境から `npm run build` → `npm run test:e2e` を実行してください。E2Eのスクリーンショットは成功時に `docs/screenshots/`、失敗時の詳細は `test-results/` に出ます。テストは独立したブラウザプロファイルを使います。
